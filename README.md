# Interactive Calculator & Unit Converter

# Python Development Internship - Task Portfolio

This repository contains all the completed tasks for the Python Development internship track, structured and organized for mentor evaluation.

## Task 1: Interactive Calculator & Unit Converter
A beginner-friendly Command Line Interface (CLI) Python program built to handle basic arithmetic operations, metric/imperial unit conversions, and currency conversions with complete input validation.

### Features
* **Basic Arithmetic:** Supports addition, subtraction, multiplication, and division with division-by-zero checks.
* **Unit Conversions:** Converts Kilometers to Miles, Miles to Kilometers, Celsius to Fahrenheit, and Fahrenheit to Celsius.
* **Currency Conversions:** Supports conversion pairs across USD, EUR, and INR.
* **Input Validation:** Built using robust `while` loops and exception handling (`try-except`) to safely manage invalid user entries.

## Task 2: Number Guessing Game & Word Counter
A multi-functional Python CLI application featuring a terminal-based randomized number guessing game and a file-based word frequency analysis tool.

### Features
* **Number Guessing Game:** Uses Python's `random` module with an attempt counter and scoring system.
* **Word Counter Tool:** Reads text directly or from files, normalizes text using regex, and calculates frequencies using `collections.Counter`.

## Task 3: Personal Expense Tracker with CSV
A Python CLI application designed to record, manage, and persist daily personal expenses into a structured CSV file with category breakdown summaries.

### Features
* **Expense Management:** Add new expenses with details including item name, amount, category, and date.
* **Persistent Storage:** Automatically reads and writes expense entries to a local `expenses.csv` file.
* **Statistical Summary:** Automatically calculates total spending and provides category-wise expenditure breakdowns.
